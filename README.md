Hi, I'm Vayun. I'm a student, and I build tools I end up using every day.

- [cliproxy-rs](https://github.com/vayungodara/cliproxy-rs): a Rust rewrite of CLIProxyAPI. One local endpoint that translates between the Anthropic, OpenAI and Gemini APIs. I kept the Go version's config, auth files and management API the same, so you can swap binaries in either direction.
- [Spawnpoint](https://github.com/vayungodara/spawnpoint): a self-hosted Minecraft panel. Every mod install is boot-tested, then a real headless client joins a throwaway copy of the server, so a broken pack never reaches your friends.
- [jev-lint](https://github.com/vayungodara/jev-lint): lints a Markdown knowledge base (an Obsidian vault or an LLM wiki) for contradictions, stale claims, unresolved markers and missing links.
- [LockIn](https://github.com/vayungodara/lockin): a student accountability app that runs on social pressure instead of reminders. Your group sees when you miss a commitment. Alpha, with a new version on the way.
